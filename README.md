# クローゼット適正枚数診断＆ミニマルワードローブシミュレーター

週の洗濯頻度や外出スタイルから、自分に必要な洋服の最低限・適正枚数を算出し、クローゼットの断捨離を支援するツール

## 🌟 主な特徴
- **完全フロントエンド完結**: サーバー不要でブラウザを開くだけで即座に動作。
- **安心・安全**: データはブラウザのローカル環境のみで処理され、外部への通信は行いません。
- **モバイル対応**: スマートフォン・PCのどちらでも直感的に使えるレスポンシブ設計。

## 🚀 使い方
1. リポジトリ内の `index.html` をブラウザで開きます（または GitHub Pages でアクセス: https://kam2525-hub.github.io/closet-minimal-wardrobe-calculator/）。
2. 画面の指示に従って操作します。
